# Milestone 5 verification

Date: 10 November 2026. Release checkpoint: `v0.5.0`.

B1 adds detailed diagnostics while preserving version 1 result categories and
exit codes. B2 declares literal versus rendered Markdown and rejects recognized
leading YAML/TOML metadata blocks. B3 adds book-wide `split_level` values 1–6,
with default H1 behavior retained. The user authorized commits, tag, push and
release, followed by a practical three-run milestone 5a comparison.

## Automated evidence

Rust 1.95.0: formatting, Clippy with warnings denied and 39 ordinary regression
tests pass. Two separately invoked independent-validation tests pass using
EPUBCheck 5.3.0: seventeen text/Markdown/mixed publications (including six
split-level variants) and four cover publications. An additional H2 reader
fixture passed with zero errors or warnings.

Tests exercise source locations through CRLF normalization, Unicode columns,
inline images, HTML, task lists, malformed tables, reference-style links and
links in notes. Broad `invalid_input` remains present alongside distinct
`issue_code` and repair fields. Invalid content preserves an existing output.
Footnote semantic errors retain a source reference but may lack a location;
other unlocalized errors report null fields rather than fabricated positions.
The request parser reports syntax/type locations in its JSON document.

The historical market probes are rerun with current expectations. Tables and
notes now succeed; inline images, task lists, HTML, recognized front matter and
broken links fail with declared detailed codes. Math/strike/alert markers
retain their text. Ordinary dollar signs, tildes and a leading thematic break
followed by prose do not produce extension warnings or front-matter rejection.

All six split levels produce equivalent chapter/navigation resources through
direct files, file requests and streamed inline content. Fixtures cover source
boundaries, preambles, skipped ranks, duplicates, quoted headings, links and
cross-chapter note returns. The title-plus-H2 fixture creates four chapters and
five contents entries, preserving its introduction and original heading ranks.
Default H1 table/note/report regressions remain covered. Invalid split types,
out-of-range values and request/CLI split conflicts fail.

The macOS release archive passes clean-install smoke checks with Rust and Java
absent from PATH. The packaged binary exercises all three ordinary and H2 input
modes, detailed diagnostics, output preservation and failed/unrun checks.
All native gates passed in [branch CI](https://github.com/benvds/agent-epub/actions/runs/42787388529)
on commit `d25689f29ad16bf7b82f8c8c4d5db8929cfe7442`. The
[tag workflow](https://github.com/benvds/agent-epub/actions/runs/42788266538)
repeated every gate and published [v0.5.0](https://github.com/benvds/agent-epub/releases/tag/v0.5.0).
All three published native smoke reports identify the exact archive hashes and
pass H2 input modes and detailed diagnostics. ZIPs, individual checksums,
SHA256SUMS and native smoke reports are attached to the release.

with `split_level: 2` and checked in two independent implementations.

| EPUB.js 0.3.93 with JSZip 3.10.1, in-app browser | Loaded all five contents entries. Detail reached the H4 within Methods; the second Results entry reached the distinct fourth chapter. reader compatibility or every publication's appearance.

## Performance

Thirty optimized runs on local macOS arm64 measured a 35.786 ms median,
51.853 ms 95th percentile and 64.946 ms maximum. The existing workload contains
100,000 base prose words, 40 chapters/tables/notes, 80 note references/section
entries and a 9,722,608-byte PNG cover. Timing includes startup, decoding,
generation, structural checks and publication; external EPUBCheck is excluded.
The milestone 3 median was 35.353 ms on its recorded environment. These are
bounded local observations, not a general performance guarantee or an agent
workflow comparison. [Raw measurements](milestone-5-benchmark.json).

The separate [milestone 5a comparison](MILESTONE_5A.md) is complete with three
paired workflows, as requested by the maintainer. Claude/Ollama evaluations remain deferred. Aggregate preflight,
front-matter metadata import and new publishing features are outside this release.

## v0.5.1 invalid-input follow-up

Final review reproduced a panic (exit 101 with empty JSON stdout) for a link to
a supplied source consisting only of a footnote definition. Such a source is
known by path but produces no chapter; the destination lookup indexed a missing
chapter map entry. The lookup now returns the same localized `unresolved_link`
diagnostic as other unavailable chapter targets. A CLI regression checks exit
2, clean JSON, the source line and existing-output preservation. Valid-book
reading resources are unchanged. Formatting, Clippy and all 40 ordinary tests pass locally. The macOS archive
passes the clean-install smoke suite. H2 chapter/navigation resources are
byte-identical to v0.5.0. All native gates and publication passed in the
[v0.5.1 tag workflow](https://github.com/benvds/agent-epub/actions/runs/42792872469)
on commit `b5ff7b01479662840f3b2e80bbb55e0ba0804c3c`. The
[v0.5.1 release](https://github.com/benvds/agent-epub/releases/tag/v0.5.1) includes
all three archives, checksums and native installation reports. Milestone 5a
measurements remain pinned to v0.5.0.
