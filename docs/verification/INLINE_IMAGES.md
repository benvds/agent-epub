# D1 Local inline images verification

Selected 10 November 2026 as the next implementation priority at the
maintainer's request. Implementation and verification are in progress on main;
published v0.5.1 remains a cover-only release.

Scope and acceptance gates are in the [roadmap](../ROADMAP.md#next-delivery-d1-local-inline-images).
JPEG/PNG source-relative assets, supplied alternative text or an explicit
decorative marker, bounded loading, protected output and version 1 inputs are
required. Remote fetching, SVG and animation are outside this package.

Automated regression, independent EPUBCheck, reader checks and performance
results will be recorded here as they are completed. No unrun check is claimed
as a pass.
